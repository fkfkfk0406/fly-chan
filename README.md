# ONNA: 초파리 뇌를 가진 소녀

초파리 전뇌 커넥톰(FlyWire v783, 뉴런 138,639개, 시냅스 5,449만 개)을 브라우저에서 LIF 모델로 실시간으로 돌리는 3D 다마고치입니다. 방 안의 온나(VRM + 더듬이·날개)는 그 뇌의 출력으로 먹고, 놀라고, 더듬이를 손질합니다.

**화면**
- **방:** 전체 화면 3D 디오라마입니다. 드래그로 돌리고 휠로 확대할 수 있고, 온나를 탭하면 쓰다듬어요. 머리 위 말풍선으로 반응을 보여 줍니다.
- **상단 게이지:** 배부름, 기운, 기분, 청결, 애정. 📔 버튼을 누르면 일기(함께한 날, 최근 사건)가 열립니다.
- **하단 돌봄:** 🍓 밥, 💬 대화, ✋ 쓰담, 🧹 청소, 😈 장난(쓴 버섯 주기, 깜짝 놀래키기), 💡 불 끄기/켜기, 🧠 뇌 보기
- **뇌 보기:** 뉴런 점 구름, 하강·운동 뉴런 발화율, 지금 들어오는 감각 입력, 행동의 원인, 시뮬 속도를 보여 줍니다.

| 돌봄 | 뇌에 들어가는 입력 | 뇌가 결정하는 반응 |
|---|---|---|
| 밥 주기 | 당 GRN (배고플수록 셈) | MN9 → 먹기. 배부르면 반응이 약해 "배불러~" |
| 쓴 버섯 | 쓴맛 GRN | MN9 억제 → 안 먹고 물러남 |
| 쓰다듬기, 벽에 부딪힘(닿는 순간 한 번) | JO-F 접촉 | 그루밍 DN → 더듬이 손질 |
| 깜짝 놀래키기 | LPLC2 루밍 | Giant Fiber → 도약 |
| 불 끄기 | R7·R8 빛 입력 끔 | (졸리면 침대로 가서 잠) |

**첫 만남**
- 처음 열면 뇌 데이터를 받는 동안 캐릭터 이름(기본 "온나")과 나를 부를 호칭(기본 "너")을 정합니다. 대사에는 받침에 맞는 조사로 들어가요(`src/story/personalize.ts`).

**난이도: 초파리의 마음은 쉽게 열리지 않아요**
- 애정 5%, 낯섦 단계에서 시작합니다.
- 애정은 하루(게임 시간 24시간)에 최대 6%까지만 오르고, 깎이는 건 제한이 없어요.
- 다음 단계로 가려면 애정, 함께한 날(친구 1일, 호감 3일, 두근두근 5일, 연인 7일), 그 순간 기분 60% 이상을 모두 채워야 합니다.
- 놀래키기 −5%, 쓴 버섯 −4%, 자는데 깨우기 −3%, 쓰다듬기 연타 −2%, 방이 많이 지저분하면 시간당 −1%, 하루 넘게 안 오면 하루당 −2%.
- 기분이 나쁘면 쓰다듬어도 애정이 오르지 않고, 밥은 배고플 때 줘야 마음이 움직입니다.
- 일기에서 오늘 모은 마음(♥ 5칸)과 다음 단계까지 남은 조건을 볼 수 있어요.

**관계와 대화** (`src/story/`)
- 애정에 따라 관계가 낯섦 → 친구 → 호감 → 두근두근 → 연인으로 깊어지고, 단계가 오를 때마다 얼굴 클로즈업과 선택지 이벤트가 나옵니다.
- 그날 처음 열면 시간대 인사(아침·점심·저녁·밤)를 하고, 12시간 넘게 비웠다 오면 삐친 대사로 시작해요.
- 💬 대화는 이미 도달한 관계 단계의 주제에서 최근에 안 한 이야기를 고릅니다.
- "오늘" 이야기는 실제 기록을 읽어요: 오늘 먹은 딸기 수, MN9가 섭식을 일으킨 시간, 그루밍 DN이 손질을 일으킨 시간, 놀란 횟수.
- 대사는 미리 쓴 대본입니다(뇌가 문장을 만들지는 않아요).
- 연출: 대사 표정과 말하는 입, 하트·반짝이 파티클, WebAudio로 합성한 효과음(🔊 버튼으로 끄기).

**돌봄 상태** (`src/care/Care.ts`)
- 브라우저에 저장되고, 앱을 닫아 둔 시간(최대 72시간)만큼 흘러갑니다.
- 배고픔은 시간당 0.3, 졸림은 시간당 0.2 늘고, 잠을 자면 15분 안에 회복됩니다.
- 방바닥에 1.5시간마다 먼지가 쌓이고(최대 6개), 딸기를 먹으면 과즙 얼룩이 남습니다. 🧹 청소로 한 번에 치우거나 얼룩을 탭해 하나씩 닦을 수 있고, 지저분할수록 기분이 떨어집니다.
- 쓰다듬기와 밥은 기분·애정을 올리고, 놀래키기와 쓴 버섯은 깎습니다. 연달아 너무 많이 쓰다듬으면 싫어해요.
- 애정이 높으면 가끔 화면 앞으로 다가와 사용자를 봅니다.
- **뇌와의 관계:** 배고픔만 뇌 입력(당 GRN 세기)에 반영됩니다. 기운, 기분, 청결, 애정은 뇌 밖의 게임 상태예요.

단축키: F(밥), T(대화), P(쓰다듬기), C(청소), Space/Enter(대사 넘기기), L(불), B(뇌 보기), Esc(패널 닫기)

## 실행

```bash
npm install
python -m venv pipeline/.venv
pipeline/.venv/Scripts/python -m pip install pandas pyarrow numpy   # macOS/Linux: pipeline/.venv/bin/python
npm run data      # 원본 약 140 MB 다운로드 → public/data/ 에 약 91 MB 바이너리 생성, VRM 모델 다운로드
npm run dev       # http://localhost:5173
```

- `?dt=0.25`처럼 적분 간격을 바꿀 수 있습니다. 기본값은 0.5 ms입니다.
- `?time=60`처럼 돌봄 시간을 빠르게 흘릴 수 있습니다(1분 = 1시간). 시연용입니다.
- `?adapt=300:1`처럼 발화 빈도 적응을 켤 수 있습니다(τw 300 ms, 발화당 1 mV). 기본은 꺼져 있습니다(아래 "적응" 참고).
- `npm test`는 엔진 테스트(합성 네트워크 검증, 실제 커넥톰에서 논문 결과 재현)와 돌봄 상태 테스트(저장, 닫힌 시간 경과, 이벤트)를 돌립니다.
- `npm run probe -- sugar:150`은 감각 그룹을 자극하고 가장 많이 발화한 하강·운동 뉴런을 출력합니다.
- `node scripts/bench.ts`는 대표 상황에서 시뮬 속도를 잽니다.
- `node scripts/adapt.ts 300:1 500:2`는 적응 파라미터별로 감각 적응, 냄새 폭주, 속도를 한 번에 비교합니다.

## 동작 원리

```
돌봄 버튼·방 안 사건 ──Poisson 입력──▶ LIF 전뇌 (Web Worker)
   ▲                                          │ 하강·운동 뉴런 발화율
   │ 배고픔                                   ▼
돌봄 상태 (Care) ◀── 이벤트 ── Controller (행동 선택 + VNC 대역)
   │ 기분                                     │
   ▼                                          ▼
표정·말풍선 ──────────────────────▶ VRM 포즈·날개·더듬이 (방 3D)
```

**뇌 (`src/sim/lif-engine.ts`)**
Shiu et al. 2024 (Nature) Brian2 모델과 같은 방정식과 파라미터를 씁니다.
- 방정식: `dv/dt = (v0 − v + g)/τm`, `dg/dt = −g/τs`
- 파라미터: 시냅스당 0.275 mV, 지연 1.8 ms, 불응기 2.2 ms
- 적분: 정확해로 적분하고, 휴지에서 벗어난 뉴런만 갱신합니다.

**입출력 뉴런 (`pipeline/build_connectome.py`)**

| 입력 | 뉴런 | 출력 | 뉴런 |
|---|---|---|---|
| 먹이 접촉 | 당 GRN | 섭식 | MN9 |
| 쓴 먹이 | 쓴맛 GRN | 도약 | Giant Fiber (DNp01) |
| 벽·쓰다듬기 | JO-F | 그루밍 | DNg84·DNg29·DNg57 |
| 위협 | LPLC2 | 전진 / 후진 | DNp09 (P9) / MDN |
| 빛 | R7·R8 | 회전 | 좌우 DNa01·DNa02 |

**테스트로 확인한 재현 결과** (`tests/lif-engine.test.ts`)
- 당 GRN → MN9 발화
- 쓴맛 동시 자극 → MN9 억제
- JO-F → 그루밍 DN
- LPLC2 → Giant Fiber
- 자극이 없으면 전뇌가 조용함
- (합성 네트워크) 지연·불응기 타이밍, 적응을 켜면 지속 자극에서 발화율 감소

## 한계와 설계상 선택

- **VNC가 없습니다.** FlyWire는 뇌만 포함하므로 보행 리듬 생성기, 벽·침대 피하기, 먹이·침대·사용자에게 가는 드라이브는 `src/behavior/Controller.ts`에서 절차적으로 만듭니다. 섭식·그루밍·도약은 뇌 출력이 결정하고, P9·MDN·DNa01/02 발화는 속도와 회전에 더해집니다. UI의 "원인" 줄에 행동마다 뇌 출력인지 VNC 드라이브인지 표시합니다.
- **후각 입력은 뺐습니다.** 식초 계열 ORN(DM1·VA2·DM4)을 10 Hz로만 자극해도, 자극을 끊은 뒤 약 1만 개 뉴런이 계속 발화하는 폭주 상태에 빠집니다(`scripts/persist.ts`). 그래서 먹이를 찾아가는 것은 VNC 드라이브가 맡습니다. 원인을 추적한 결과는 이렇습니다.
  - 폭주 발화의 40%는 Kenyon cell이지만, KC 출력을 모두 끊어도 폭주는 계속됩니다. KC는 원인이 아니라 결과입니다.
  - 더듬이엽 국소 뉴런(ALLN, 429개) 출력을 끊으면 폭주가 사라집니다. 이 뉴런들은 신경전달물질 예측 신뢰도가 평균 0.46으로 낮고, 실제로는 대부분 억제성인데 아세틸콜린·세로토닌·도파민으로 예측돼 흥분성으로 들어간 경우가 많습니다.
  - 다만 부호를 보정해도 실험으로 확인된 흥분성 LN을 살리면 폭주가 일부 남고, 폭주를 잡아도 좌우 냄새가 회전 DN의 좌우 차이로 이어지지 않아 냄새 추적에는 쓸 수 없었습니다.
- **적응은 옵션입니다.** 발화할 때마다 커지고 천천히 사라지는 적응 전류를 엔진에 넣었습니다(`Adaptation`, 원 모델에 없음). 모든 뉴런에 같은 적응을 걸면 절충이 생깁니다(dt 0.5 ms, `scripts/adapt.ts`).

  | 설정 | 당 150 Hz 3초 동안 MN9 (0.5초 단위) | 냄새를 끊은 뒤 300-600 ms 발화 |
  |---|---|---|
  | 적응 없음 | 112 → 92 Hz | 262,413 |
  | τw 300 ms, b 1 mV | 44 → 30 Hz | 85,090 |
  | τw 500 ms, b 2 mV | 16 → 4 Hz | 0 |

  폭주를 멈출 만큼 세게 걸면 섭식 반응이 거의 사라져서, 기본값은 끔으로 두었습니다.
- **그루밍 DN은 데이터로 골랐습니다.** JO-F 자극에 선택적으로 반응하는 하강뉴런을 `scripts/probe.ts`로 찾았습니다.
- **dt 0.5 ms**는 Brian2 기본값(0.1 ms)보다 거칠지만, 위 재현 테스트는 dt 0.25와 0.5에서 모두 통과합니다. 루밍 자극 직후처럼 수만 개 뉴런이 활성화되면 시뮬이 실시간보다 느려지고, 세계도 같은 비율로 느려집니다(시뮬 속도 표시).
